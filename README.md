- 🛡️ **AI Threat Scenario Generator & Assurance Suite (\`Python\`, \`Gemini 3.8 Flash\`, \`PostgreSQL\`, \`Docker\`):** Engineered an automated security testing suite generating threat scenario specifications across 5 families (RAG poisoning, tool misuse, multi-agent trust hijacking, memory dilution, exfiltration). Implemented a 1,040-trial release protocol evaluating 14 release gates, backed by 101 unit tests, a PostgreSQL exporter, and a web console UI.
- 🎙️ **Apex Multilingual Local Voice Agent (\`Python 3.12\`, \`FastAPI\`, \`Ollama Gemma 3\`, \`faster-whisper\`, \`Edge-TTS\`):** Architected a privacy-first, low-latency voice agent with fluid turn-by-turn multilingual mirroring (Marathi Devanagari, Hindi, English). Integrated Silero VAD v5, CPU-optimized int8 Whisper transcription, Edge-TTS speech synthesis, Twilio telephony webhooks, and 136 automated test cases.

Implemented negative feature suppression for heatsinks/cooling fins, OpenCV HUD overlay rendering, and instant dataset export to Ultralytics YOLOv8, CVAT 1.1, and COCO 1.0.

Deployed live on Streamlit Cloud ([Live Demo](https://prashant7972-rag-project-app-akxla5.streamlit.app/)).
